Website Footprinting and Reconnaissance

Project Overview

This project documents my hands-on learning experience with website footprinting and reconnaissance using command-line tools.

The practical exercise explored how publicly available information about a website can be collected and analysed to understand its digital environment.

Objectives

- Understand the concept of website footprinting and reconnaissance.
- Explore publicly available domain and DNS information.
- Identify website technologies and server information.
- Inspect HTTP response headers.
- Understand the purpose of Web Application Firewall (WAF) detection.
- Learn how reconnaissance supports both offensive and defensive cybersecurity.

Tools Used

Tool| Purpose
WHOIS: Retrieve domain registration information.
WhatWeb: Identify website technologies.
nslookup: Resolve domain names and examine DNS information.
cURL ("-I"): Inspect HTTP response headers.
WAFW00F: Identify the presence of a Web Application Firewall.
DNSRecon: Enumerate DNS records.

Key Learning

Reconnaissance is the process of gathering information about a target to understand its digital environment, identify potential exposure, and support subsequent security assessment or defensive actions.

Attackers may use this information to identify potential opportunities for an attack, while defenders can use it to understand their organisation's exposure and improve security.

Ethical Considerations

This repository is for educational purposes. All testing should be performed only on systems you own or have explicit permission to assess.

Sensitive information and target-specific findings should not be published without authorisation.
